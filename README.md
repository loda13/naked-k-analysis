# 📊 Stock MA Analysis

均线密集度分析系统 — MA/EMA 六线密集度 + 裸K形态分析

## 功能

### 双均线密集度分析 (`ma_analysis.py`)

基于 MA20/60/120 + EMA20/60/120 六线系统，多时间级别（4h / 日线 / 周线）扫描：

- **均线密集度** — 极度密集(<2%) / 较为密集(<4%) / 未密集
- **信号判定** — 密集+K线在上方=买入 / 密集+K线在下方=卖出
- **回踩MA20检测** — 回踩不破确认加仓信号
- **假突破/假跌破检测** — 识别诱多/诱空陷阱
- **均线密集台阶位** — 历史密集区作为支撑/压力参考
- **斐波那契回撤** — 大周期 0.236/0.382/0.5/0.618/0.786
- **ATH斐波那契扩展** — 创新高后目标位 1.618/2.618/3.618
- **斐波那契×密集区重合** — 多维度共振确认

### 裸K形态分析 (`naked_k_analysis.py`)

纯价格行为（Price Action）分析，零指标依赖：

- **K线形态识别** — 锤子线、吞没、十字星、Pin Bar 等
- **支撑/阻力位** — 前高前低、多次测试位
- **价格结构** — HH/HL（上升趋势）/ LH/LL（下降趋势）
- **关键位反应** — 价格在支撑压力位的行为

## 安装

```bash
pip install yfinance pandas numpy
```

## 使用

### 双均线分析

```bash
# 分析单只股票（默认4h+日线+周线）
python3 ma_analysis.py NVDA

# 指定时间级别
python3 ma_analysis.py 0700.HK 4h,daily

# 跑全部默认持仓（腾讯、小米、QQQ、NVDA、TSLA、PDD、泡泡玛特）
python3 ma_analysis.py
```

### 裸K分析

```bash
# 分析单只股票
python3 naked_k_analysis.py NVDA

# 指定周期和间隔
python3 naked_k_analysis.py 0700.HK 1y 1d
```

### 日报脚本

```bash
# 一键跑全部持仓的双均线分析
bash ma_daily_report.sh
```

## 信号说明

| 信号 | 含义 | 条件 |
|------|------|------|
| 🟢 买入 | 均线密集 + K线在上方 | 密集度 < 4%，收盘价高于多数均线 |
| 🔴 卖出 | 均线密集 + K线在下方 | 密集度 < 4%，收盘价低于多数均线 |
| ⚫ 观望 | 均线未密集 | 密集度 ≥ 4% |
| ⚡ 回踩加仓 | 回踩MA20不破 | 触及MA20后站稳反弹 |
| 🚨 假突破 | 站上MA20后快速跌破 | ≤5天内跌回 |
| 🟢 假跌破 | 跌破MA20后快速拉回 | ≤5天内站回，信号升级为买入 |

## 密集度等级

| 密集度 | 等级 | 含义 |
|--------|------|------|
| < 2% | 极度密集🔥 | 变盘在即，方向选择 |
| 2-4% | 较为密集⚡ | 趋势酝酿中 |
| ≥ 4% | 未密集 | 趋势已展开或无序 |
