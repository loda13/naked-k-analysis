# v5.1.0 · 趋势、量价与持仓纪律

输入股票或 ETF 代码后，中文报告会在原有双均线交易计划下方，逐条判断十项交易理念，并列出行情日期、数值和依据。直接运行即可查看日线量价与均线形态，账户和市场资料按需补充。

```bash
python naked_k_analysis.py 600000.SS 0700.HK QQQ
python naked_k_analysis.py 600000.SS --account-path account.json --context-path context.json --json
```

## 新增判断

- **趋势与量价。** 核对 MA5、MA20 上穿或跌破、明显缩量新高、放量突破后五日内的缩量回踩，以及强势日换手率。逐根跟踪“倍阳缩倍阴”从放量阳线到整理完成或低点失守。
- **持仓纪律。** 同日快照支持当前及历史最高收盘盈亏率。单笔亏损超过 5%，或达到 +15% 后回落至 +10%，报告会提示复核。结合真实持仓只数、亏损分布及 MA20 识别优先复核的弱势持仓。
- **盘中与市场环境。** 完整分时用于识别早跌收复及尾段急涨。有来源的市场广度、板块排名与资金方向、连板和炸板记录可通过 `--context-path` 补充。腾讯 A 股日线响应中的同日收盘快照可直接提供换手率及涨停价事实。
- **黄金分割。** 本版收录上次发布后加入的独立日线和周线 0.618 观察，分别列出上涨段回撤、下跌段反弹、候选锚点、确认状态与失效提示。

## 数据与兼容性

`items[].principles` 和 journal 的 `principles` 使用版本 `market-principles-v1`。每项都有固定键名、状态、说明和数值。audit 记录版本。原有双均线规则编号、命令、配置、历史日志、技术附录、风险预算和离线回测继续可用。缺少成本盈亏、盘中采样、板块或板态证据时，报告会指出所需资料。

## 发布验证

- Python 3.14 通过 336 项离线测试。覆盖阈值端点、缺量、短历史、回踩失效、三根形态的时间顺序、盈亏保护、不同市场的板态、小时数据完整性与旧报告兼容性。
- 用 2026-11-20 收盘行情运行浦发银行、腾讯和 QQQ，核对三份标的结果、Markdown、JSON、journal 及同一次 audit 的完成事件。三份报告均有十项理念判断、原有 33 项技术指标及黄金分割观察。
- 对十个标的的同批历史行情，在发布前的 `eae653c` 与本版分别复算。原有 25 个标的报告字段逐项相同，包括动作、风险计划、多周期验证和技术附录。

这些检查验证软件行为和数据链路。策略收益尚无计入成本的样本外验证。仅供学习研究，不构成投资建议。
