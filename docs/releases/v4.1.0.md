# v4.1.0 — 文字技术信号报告与短历史支持

报告新增33个技术指标条目和文字形态识别，集中列出偏多、偏空、分歧及确认条件，供用户自主判断。全部以文字和表格展示；既有v2条件计划保留为参考。

## 新增观察报告

- 覆盖MA/EMA、BBI、SAR、Aroon、TRIX、MACD、DMI/ADX/ADXR、RSI、KDJ、随机指标、Williams %R、CCI、ROC/Momentum、BIAS、布林带、ATR、历史波动率、Keltner/Donchian、相对成交量、OBV、A/D、CMF、MFI、VWMA和锚定VWAP。33个条目含多周期组合，不代表33份独立证据。
- 文字识别双/三重底顶、头肩底顶、突破/破位、假突破/假破位、回踩/反抽、探底、吞没、星线、仙人指路、背离及箱体/三角/楔形/旗形等候选，区分待确认、已确认和已失效。
- 只使用已收盘日K；通道排除信号当日，拐点确认后才参与识别。展示识别日期、确认/失效日期和适用价位，缺量或样本不足时保留不可计算状态。
- ROC与Momentum方向相反时标记分歧。观察项不评分、不按数量投票，也不修改已有v2入场、退出和风险预算规则。

## 同次发布的短历史支持

此前已合入主分支的短历史扩展在本版本正式发布：少于55根完整日K时趋势未知；55–204根使用Close/EMA20/EMA50和五日EMA50斜率，明确标注长期趋势未确认；至少205根使用原完整历史规则。

生产回测至少55根预热。评估起点缺少EMA200时，EMA50/200对照标为不可计算，不把等待期的现金曲线当作有效对照。Markdown中的结构支撑与压力显示完整区间。

## 使用与升级

```bash
python naked_k_analysis.py 0700.HK
python naked_k_analysis.py 0700.HK TSLA --json
python naked_k_analysis.py 0700.HK --news
```

- CLI入口、依赖和现有参数不变；新增计算复用pandas/numpy，不引入指标框架。
- JSON/journal使用 `technical-trend-v2`，新增 `observations` 字段，其版本为 `technical-observations-v1`；audit的 `plan_generated` 新增 `observation_version`。读取旧日志时允许新增字段缺失。
- 旧报告与日志保留；不同规则版本不能直接拼接成同一策略业绩。离线回测只评估v2趋势规则，不包含新增观察项的交易有效性验证。
- 完整定义与计算口径见[技术观察文档](https://github.com/loda13/naked-k-analysis/blob/v4.1.0/docs/technical-observations.md)。

## 验证与边界

281项离线测试通过，覆盖公式、预热、平盘/缺量/短历史、前缀一致性、形态确认与失效、方向分歧及原有风控/回测回归。2026-09-29腾讯实跑使用750根完整日K，33个指标条目均可计算；Markdown、JSON、journal和audit核对一致。

经济有效性保持 **UNVALIDATED**。形态确认不代表盈利已验证，量价代理不能判断“主力抄底”或交易者身份，超买/超卖不自动构成买卖许可。账户未知不等于空仓；软件不连接券商下单。
