# 十条交易理念如何用于一个标的

输入代码后，报告在双均线计划下方逐条给出判断。每项都有状态、中文依据和可读取的原始数值。判断日期取该标的最后一根已收盘日 K，版本为 `market-principles-v1`。交易与回测仍使用各自原有的入场、止损、目标和风险预算。

## 十项判定

| 理念 | 项目采用的判定口径 |
| --- | --- |
| 1 · 让盈利延续，控制亏损 | 以同一笔多头持仓的成本为基准。收盘亏损严格超过 5% 提示复核止损。曾有至少 +15% 的收盘盈利，现回至 +10% 或更低时提示复核利润保护。两者同时触及时优先显示亏损提示。当日盈利已达 +15% 本身即可确认保护线已启动。 |
| 2 · 成交量与突破质量 | 日量比 = 当日成交量 / 之前五个交易日均量。小于 0.5 为明显缩量，同时收盘超过此前 20 日最高价则为缩量新高，另列价格是否在上行的 MA20 上方。量比大于 1.5 且突破前 20 日高或向上穿越 MA20，记录本次突破日期和价位。此后五日可核对缩量回踩。已知当日收于涨停价且量比小于 1 时另列缩量封板。 |
| 3 · 控制持仓只数 | 对同日快照中实际正仓位去重计数。2–3 只是截图中的观察范围，4 只是参考上限。持仓超过 5 只、已知过半数亏损、本标的在持仓内且收盘低于 MA20 时，将它列入优先复核。已知空仓、盈亏未知和快照缺失各自显示。 |
| 4 · 早盘、尾盘与日线量价 | 用同一日完整分时的首根开盘、首小时最低、末根开收盘计算。首小时低于开盘至少 3% 且末根收复开盘价，记录早跌收复。末段涨幅至少 3%，记录尾段急涨。另列放量上涨或下跌、缩量上涨或下跌、放量滞涨、缩量企稳候选和巨量急涨。 |
| 5 · 顺势观察 MA5 / MA20 | 比较今日收盘与今日均线，以及昨日收盘与昨日均线。由线下或线上持平转至线上称上穿，由线上或持平转至线下称跌破。上穿且日量比大于 1.5 记为放量上穿。分别列出短线与波段的读数，允许两者给出相反方向。 |
| 6 · 市场偏弱时核对相对强弱 | 对给定盘中时点计算上涨家数 /（上涨家数 + 下跌家数）。占比不超过 20% 且标的同期涨跌幅高于指数，标为广度偏弱、个股相对抗跌。两项涨跌幅须同一时点、同一昨收基准。只解释该采样点，全日情绪最低点需要其他时点作比较。 |
| 7 · 题材、资金与承接 | 在同一板块分类和排名范围内，用涨跌幅排名前 20%、前一日及当日均上涨、来源报告资金净流入这三个条件核对板块延续。报告给出排名、两日涨跌及资金方向。消息催化由读者结合新闻事实核对，`--news` 可附日期、来源与标题。 |
| 8 · 强势日量能与换手 | 当日收盘涨幅严格大于 5%、日量比大于 1、当日换手率在 5%–30%（含端点）时符合。三项数值逐一展示。已知任何一项不符即可排除组合，其余缺项仍显示未知。 |
| 9 · 倍阳缩倍阴 | 第一天收阳、较昨收上涨超过 5%、成交量至少为前一交易日两倍。第二天收阴、量为第一天一半或更低，最低价守住首日最低价。第三根最低价继续守住、实体大小不超过自身开盘价 2% 时确认形态。按最近三根内最新的合格起始阳线，显示进展、未完成或破位。 |
| 10 · 连板分歧与一致性 | 仅对适用涨停的 A 股标的判断。此前至少连续两个交易日收于涨停，当日有经来源确认的炸板记录且量比大于 1.5，标为分歧候选。当日收于涨停且量比小于 1，标为一致性候选。日高触及涨停、收盘离开该价，只能确认触板未收住，曾否封板仍需分时记录。 |

**回踩的时间顺序。** 每次仅检查当日及前五个交易日的最近一次合格突破。两种突破同时出现时优先使用前 20 日高，否则冻结突破日的 MA20。之后每根收盘须守在冻结价位或以上。回踩当天收盘低于昨日，低点到达突破位上方 1% 范围内或更低、收盘仍守位，且日量比小于 1、成交量低于突破日，才记为“缩量回踩守位”。中途收盘失守会显示失效。

**量价细节。** 量比大于 1.5 且涨跌幅绝对值不超过 1% 记为放量滞涨或横盘。前日下跌、当日涨跌幅绝对值不超过 1% 且量比小于 0.5，记为缩量企稳候选。量比至少 2 且涨幅超过 5% 记为巨量急涨。当前或所需五日中任何一天成交量为零或缺失，日量比留空。原技术附录的 20 日相对量保留原定义。

图中文字给出的 5%、15%/10%、量比和换手区间在上表明示。20 日新高、五日回踩窗口、分时 3%、广度与板块排名、阳线和小实体的数值界限属于本项目的工程约定。截图里的收益、胜率和次日走势断言缺少样本及成本验证，本模块只输出可查证的条件和价格行为。

## 数据从哪里来

- **每日行情。** 日 K 用于均线、日量比、涨跌和 K 线组合。突破位排除信号日。小时 K 只用于当日分时节奏，完整日 K 依然可以独立评估。
- **分时。** 对腾讯 A 股使用当地结束时间 10:30、11:30、14:00、15:00 四根小时 K。对 Yahoo 美股、港股、韩股核对当地开盘起的完整小时格线。尾段指最后一根行情柱，美股和港股常规交易日的这一根可能只有半小时。交易日尚未收盘、缺少任何一格、出现零量占位柱或缺少已核验的行情源时，自动分时读数留空。节假日、半日市和异常交易时段需要另外核实。
- **A 股收盘快照。** 当腾讯日线响应附带同代码、同交易日的收盘后报价时，读取其换手率、原始最高价、原始收盘价及当日公布的涨停价。三种价格取自同一快照。收盘前报价、日期错配与无效字段不回填到历史。涨停价缺失时板态留空。字段映射及原始报价格式可核对公开解析实现。[腾讯行情字段映射](https://github.com/shidenggui/easyquotation/blob/master/easyquotation/tencent.py)
- **真实账户。** `--account-path` 支持可选的 `pnl_pct` 和 `peak_pnl_pct`。最高值从建仓起按同一成本口径统计完整收盘，计入起始的 0% 和当前值。未提供最高值时，报告只判断当前盈亏能证实的条件。组合亏损多数按已知数和未知数的上下界判断。输入代码列表仅指定要分析的标的。[账户示例](../account.example.json)

## 补充同日资料

```bash
python naked_k_analysis.py 600000.SS 0700.HK --context-path context.json --json
```

`context.json` 的顶层键是大写标的代码。每个条目必填 `as_of`（行情当地日期，`YYYY-MM-DD`）与单行 `source`（可辨认的实际来源）。只填写有依据的资料组。过期或未来日期只展示来源及日期，同日自动行情仍可用。相同字段以显式同日换手率、板态资料为先。分时涨跌优先取完整行情格线。示例文件中的数值均为虚构。[补充资料示例](../context.example.json)

| 可选字段 | 含义 |
| --- | --- |
| `turnover_pct` | 行情日换手百分数，8.2 表示 8.2%。应核对数据源采用的流通股本口径。 |
| `limit_state` | `closed` 收于涨停，`opened` 有实际封板后打开且收盘未封住的记录，`touched_unsealed` 触价后未收住、是否封过未知，`untouched` 未触板，`no_limit` 当日不适用涨停。 |
| `prior_limit_up_days` | 截至前一交易日连续收于涨停的交易日数，不含当日。 |
| `session` | `opening_low_pct` 为首小时最低较开盘涨跌，`close_from_open_pct` 为全时段末根收盘较首根开盘涨跌，`last_bar_pct` 为尾段较该段开盘涨跌。三者使用同一日、同一价格口径。 |
| `stress` | 同一交易时点的当地 `time`（HH:MM）、`advancers`、`decliners`、`ticker_change_pct`、`index_change_pct`。涨跌家数需来自一致的市场范围，分母为零时占比未知。 |
| `sector` | `name`、`rank`、`count` 指板块、当日涨跌幅排名和参评板块总数，`change_pct` 和 `previous_change_pct` 为两日涨跌。可选 `flow_direction` 取 `in`、`out` 或 `flat`，按该数据源的资金统计定义填写。 |

JSON 和 journal 在每个标的的 `principles` 保留 `version`、`as_of`、补充资料日期与来源、可用的行情快照，以及十个有固定键名的 `checks`。各项的 `status`、`detail` 和 `values` 分别给出状态、解释和数值。audit 的 `plan_generated.principles_version` 记录该次口径。历史日志可以缺少整个 `principles` 字段。
