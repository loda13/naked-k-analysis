## 🔧 技术实现

### 数据流

```
OHLCV数据
    ↓
naked_k_zones (供需区)
    ↓
naked_k_smart_money (主力分析)
    ├─ 成交量异常检测
    ├─ 价格行为分析
    ├─ 多周期对齐
    └─ 概率评分
    ↓
InstrumentReport
    ↓
交易员简报
```

### 核心算法

**吸筹识别**:
```python
IF 成交量 > 均量 × 2.0
AND 收盘在K线上半区
AND 价格窄幅震荡
→ 吸筹信号
```

**卖压衰竭**:
```python
IF 价格创新低
AND 成交量 < 均量 × 80%
AND 下跌速度减半
→ 卖压衰竭
```

## ⚠️ 注意事项

### 使用限制

1. **概率优势，非确定预测**
   - 主力也会失败
   - 建议置信度>70%才参考

2. **必须配合技术面**
   - 不能单独作为入场依据
   - 需结合价格结构和风控

3. **市场差异**
   - A股/港股/美股行为不同
   - 可能需要调优参数

### 无法识别

- ❌ 大单逐笔追踪 (需tick数据)
- ❌ 资金流向 (需专业数据源)
- ❌ 机构持仓 (需披露数据)
