# 主力抄底识别功能 - 使用指南

## 快速开始

主力抄底识别功能**已默认启用**，无需任何配置即可使用。

```bash
# 直接运行，主力分析自动生效
python naked_k_analysis.py
```

## 在报告中查看结果

### 1. 交易员简报中的主力行为

查看生成的 Markdown 报告，找到"交易员简报"部分：

```markdown
- 交易员简报：
  状态：低波动压缩；
  力量：趋势结构向下、波幅连续收敛...
  主力：主力抄底概率 92%。检测到：吸筹信号(developing, 92%)；
  区域：下方：需求区 436.0-436.0...
```

### 2. 理解主力信号

**主力抄底概率 XX%**
- 75%以上：强烈信号，主力可能在建仓
- 50-75%：中等信号，有一定参考价值
- 50%以下：弱信号，可忽略

**信号类型**：
- **吸筹信号** - 放量但价格窄幅震荡
- **卖压衰竭** - 新低但量能萎缩
- **多周期共振** - 日/周/月需求区重叠
- **流动性扫荡** - 假跌破后快速拉回

**强度等级**：
- `strong` - 强信号，多个条件完全满足
- `developing` - 中等信号，主要条件满足
- `weak` - 弱信号，仅部分条件满足

## 配置选项

### 禁用主力分析

如果不需要主力分析，创建 `config.json`：

```json
{
  "smart_money": {
    "enabled": false
  }
}
```

运行：
```bash
python naked_k_analysis.py --config-path config.json
```

### 调整灵敏度

**提高门槛**（减少信号，提高精度）：
```json
{
  "smart_money": {
    "enabled": true,
    "volume_anomaly_threshold": 3.0,      // 从2.0提高到3.0
    "exhaustion_volume_ratio": 0.6        // 从0.8降低到0.6
  }
}
```

**降低门槛**（增加信号，可能增加噪音）：
```json
{
  "smart_money": {
    "enabled": true,
    "volume_anomaly_threshold": 1.5,      // 从2.0降低到1.5
    "exhaustion_volume_ratio": 0.85       // 从0.8提高到0.85
  }
}
```

### 完整配置示例

参考 `config.example.json`：
```json
{
  "risk": {
    "account_risk_pct": 1.0,
    "max_drawdown_pct": 8.0
  },
  "portfolio": {
    "max_total_gross_pct": 80.0

```

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `enabled` | `true` | 是否启用主力分析 |
| `volume_anomaly_threshold` | `2.0` | 异常成交量倍数（越大越严格） |
| `sweep_recovery_threshold` | `0.9` | 扫荡收回比例（0.9 = 90%） |
| `exhaustion_volume_ratio` | `0.8` | 衰竭成交量比率（0.8 = 80%） |
| `confluence_weight` | `1.2` | 多周期共振权重加成 |

## 实战使用建议

### 1. 配合技术面使用

**✅ 正确用法**：
```
技术面: 日线下降结构，观望
主力面: 抄底概率 92%，吸筹信号
→ 决策: 降低仓位做多试错，严格止损
```

**❌ 错误用法**：
```
技术面: 观望
主力面: 抄底概率 92%
→ 决策: 直接满仓做多 ❌ (忽略技术面风险)
```

### 2. 置信度阈值

- **>80%** - 高置信度，可作为重要参考
- **70-80%** - 中高置信度，辅助决策
- **50-70%** - 中等置信度，谨慎参考
- **<50%** - 低置信度，建议忽略

### 3. 信号组合

**最强信号组合**：
- 吸筹 + 卖压衰竭 + 多周期共振
- 置信度通常 >85%

**一般信号**：
- 单一吸筹信号
- 置信度 60-75%

### 4. 风险控制

即使主力概率很高，也要：
1. ✅ 设置止损位
2. ✅ 控制仓位
3. ✅ 等待技术确认
4. ✅ 遵守风控规则

**不要因为主力信号而**：
- ❌ 放弃止损
- ❌ 加大仓位超过计划
- ❌ 逆势重仓

## 常见问题

### Q: 主力信号准确吗？

A: 这是**概率优势**，不是100%准确。主力也会失败，信号只是提供额外维度的参考。建议置信度>70%才作为辅助决策。

### Q: 为什么有时候没有主力信号？

A: 正常情况。只有满足特定条件时才触发信号：
- 成交量异常放大
- 价格行为符合吸筹/衰竭特征
- 多周期结构对齐

大部分时间市场处于常态，不会触发信号。

### Q: 可以只看主力信号交易吗？

A: **不建议**。主力分析只是辅助工具，必须配合：
- 价格结构分析
- 供需区判断
- 风险管理
- 资金管理

### Q: A股、港股、美股的主力行为有差异吗？

A: 有差异。建议：
- **A股**: 可能需要提高阈值（主力行为更明显）
- **港股**: 默认参数适用
- **美股**: 可能需要降低阈值（主力行为更隐蔽）

具体调优需要回测验证。

### Q: 主力信号和技术信号冲突怎么办？

A: 优先考虑技术面，主力信号作为辅助：

| 技术面 | 主力面 | 建议操作 |
|--------|--------|----------|
| 买入 | 抄底概率高 | 正常建仓 |
| 观望 | 抄底概率高 | 小仓试错 |
| 回避 | 抄底概率高 | 观望为主 |
| 买入 | 派发概率高 | 降低仓位 |

### Q: 如何验证主力信号的效果？

A: 建议回测方法：
1. 记录每次主力信号
2. 跟踪后续5日/10日收益
3. 统计不同置信度区间的胜率
4. 调整阈值参数

项目未来会提供回测工具。

## 技术原理（简化版）

### 吸筹识别
```
IF 成交量 > 20日均量 × 2.0
AND 收盘价在K线上半区
AND 连续2-3根价格窄幅震荡
THEN 判断为吸筹
```

### 卖压衰竭
```
IF 价格创10日新低
AND 成交量 < 20日均量 × 80%
AND 下跌速度 < 前期速度 × 50%
THEN 判断为卖压衰竭
```

### 多周期共振
```
IF 日线价格 在 周线需求区内
AND 周线需求区 在 月线需求区内
AND 区域强度 >= developing
THEN 判断为多周期共振
```
