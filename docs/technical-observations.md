## 报告约定

- 先展示偏多、偏空和分歧，再列形态事件及完整指标表。既有v2条件计划放在参考部分。
- 不用指标数量投票，不给综合评分或胜率；相关指标可能描述同一件事。
- 形态“已确认”仅表示满足下述几何或价格条件；待确认不等于已经触发。失败形态显示失败发生日期，不能回填到原突破日。
- 所有输入只使用完整日K；事件日期、最早识别日期、确认/失效日期分别保存。支撑压力和形态使用左右各2根确认的严格高低点；确认前不可用。同根同时构成高低点时忽略其形态顺序。
- 数值不足或不可计算保留null。零量、缺量和零分母不能造出资金流或买卖线索。OBV/A/D从输入历史起点累计，任一缺量会使之后累计值不可计算；滚动量能指标在完整窗口恢复后可重新计算。
- 观察读数可以在v2不足55根的情况下显示，但不改变v2的最低历史要求与风险保护。
- 覆盖以现有OHLCV可计算项为边界。换手率需要流通股本，委比需要盘口，逐笔主动买卖和真实资金归属需要额外数据；当前不推算、不填零，也不把OBV/CMF/MFI冒充这些数据。

## 指标口径

| 类别 | 覆盖与计算 |
| --- | --- |
| 均线 | MA5/10/20/60/120/250；EMA20/50/200及5日EMA50变化。EMA以首N项SMA初始化；BBI为MA3/6/12/24均值 |
| 趋势 | MACD(12,26,9)，柱值采用国内常见的2×(DIF−DEA)；DMI/ADX14沿用v2的Wilder实现，ADXR为ADX与14日前ADX的均值 |
| 补充趋势 | SAR步进0.02、上限0.2，前两根收盘决定初始方向，第二根以首根高/低初始化SAR、前两根极值初始化EP；以后用前两根高低限制投影值。Aroon25统计含当日26根，极值并列取最近一次；TRIX为三重EMA15单日百分比变化及9日SMA |
| 动量 | RSI6/12/14/24使用Wilder平滑，需N+1根；完全平盘取50。KDJ(9,3,3)的K/D初值50、J=3K−2D；无振幅窗口返回null并重置种子。慢速随机指标(14,3,3)采用SMA平滑 |
| 偏离 | Williams %R14范围−100至0；CCI20使用HLC3与窗口平均绝对离差、常数0.015；ROC12为百分比变化，Momentum10为价格差；BIAS6/12/24为相对MA的百分比偏离 |
| 波动 | 布林带20日MA±2倍总体标准差(ddof=0)，带宽为百分比、%B按0–1展示；ATR14/ATR%沿用v2；HV20采用日对数收益样本标准差×√252；Keltner明确采用EMA20±2ATR14 |
| 通道 | Donchian前20/55日高低，均排除当前K线 |
| 量能 | 当日量、MA5/20量、相对量=当日量/之前20日均量；此处不是盘中量比。OBV为按收盘涨跌符号累计量，首日从0起；A/D按日内收盘位置加权量累计，零振幅贡献0；CMF20为20日A/D贡献合计除以20日成交量 |

## 形态项目定义

以下阈值为固定、可复核的首版定义，并非行业唯一标准或已校准概率。所有形态按日线识别，无图表输出。

- **双底/双顶、头肩底/顶、三重底/顶**：最近120根内的3或5个交替确认拐点，相邻拐点至少间隔3根。两个端点相差不超过末端拐点当日1ATR，颈线距末端至少1ATR；第一个拐点之前10日须有超过1ATR的相反方向价格变化。三重结构的三个极值落在1ATR内；头肩结构的头比两肩极端至少1ATR。双底顶用中间极值水平颈线；五点结构连接两个中间拐点为颈线。最早在全部拐点确认后，收盘越过颈线才确认；收盘穿过整个形态极端价则失效。确认、失效或最早识别超过20根的结构不再列入当前观察。
- **突破/破位**：首次收盘越过前20日高/低；当前K线不计入边界。**盘中冲高回落/探底回收**：当日高/低越界，收盘收回区间。
- **假突破/假破位**：此前5根内存在首次收盘突破，今日首次收回原突破边界。记录原突破日期和今天的失败确认，不能提前认定。**回踩/反抽**：此前5根突破后的收盘一直在边界外，今天低/高距原边界≤0.3ATR，收盘继续保持突破方向。
- **锤头、长上影/仙人指路候选**：影线≥2倍实体（实体下限按振幅5%），另一侧影线≤振幅20%；比较前一日与10日前收盘确定背景。上涨长上影同时保留“受阻”及“延续”两种候选解释。仙人指路式延续仅在后5根内首次收盘突破原高点、期间未收破原低点后确认。单根长下影只报探底候选。
- **吞没、十字星、早晨/黄昏之星**：吞没用实体覆盖并要求此前10日方向相反；十字星实体≤振幅10%；星线采用无缺口变体，中间实体≤首根的一半，第三根反向收复首根实体中点。吞没只确认K线组合本身，星线作为待确认候选，均不宣称反转成立。
- **低位承接、高位回落**：相对量≥1.5，极值距前20日边界≤1ATR；承接要求收于当日振幅上部30%，高位回落要求收盘低于高点至少60%振幅。只描述量价行为，买卖方身份和意图未知。
- **RSI/MACD背离**：最近两个同类确认拐点相距至少5根，第二拐点确认不超过5根；价格创新低而指标抬高，或价格创新高而指标降低。只报候选，不认定反转。
- **三角/楔形/箱体/旗形**：最近三组交替确认高低点分别拟合上下边界，所有拐点残差≤0.5ATR，确认时通道宽度>1ATR。上下边界在结构跨度内相向变化各超0.3ATR为三角；一边近水平(≤0.3ATR)、另一边变化>0.5ATR为上升/下降三角；同向且宽度收缩>0.5ATR为楔形；两边变化≤0.5ATR为箱体。旗形要求边界变化差≤0.5ATR、此前10日冲量≥3ATR、整理逆向且边界变化小于冲量60%。确认后收盘越界才产生方向；重新收回通道或边界交叉视为失效。形态最早确认后20根内展示，拟合只是明确的启发式定义。
